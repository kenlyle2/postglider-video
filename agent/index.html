Need to download a clip? Set up your YouTube cookies once ▾
  1. Install a cookie-export browser extension -- e.g. Cookie-Editor (Chrome/Firefox) or "Get cookies.txt LOCALLY."
  2. Go to youtube.com while logged into the account that owns this content, open the extension, and export.
  3. Export format matters: pick "Netscape" specifically (Cookie-Editor also offers JSON and Header-string -- those will NOT work here). Export ALL cookies for the site, not a single cookie -- there's no one cookie (e.g. LOGIN_INFO alone) that's enough; YouTube's login state is spread across several (session, security-token, and login cookies together).
  4. Paste the exported text below, as-is. It's sent with your download request only, used once, and never stored or logged server-side.
